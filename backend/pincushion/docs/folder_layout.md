# Folder Layout

PinCushion organises the library by **craft**. Under each craft are two sibling trees: **patterns** (designs you own) and **materials** (stash for that craft). The library root defaults to `/data/library`.

```text
/data/library/
  materials/
     wool/
     floss/
     tools/
       needles/
       hooks/
       scissors/
     fabric/
       aida/
       linen/
  patterns/
    sewing/
      Vogue V1234/
      Simplicity ABCD/
    knitting/
      Aran Sweater/  
      Reversible Snood/
    crochet/
      Cute Bear Aragarumi/
    cross_stitch/
      Fox Kit/
  …
```

## Craft

Folder names match craft ids used elsewhere in PinCushion. See Craft Specifics for exact tags. Anything unrecognized will be entered in a new category which matches the given file name.

## Patterns

Each pattern folder holds a particular project's design files. PinCushion may add derived files here too.

## Materials

Materials are resources that may or may not span several crafts: e.g. yarns, hooks, needles, floss, fabric, drills, beads, and so on. See the seperate Material documentation page for more information
